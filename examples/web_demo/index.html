Rubric Forecast — local demo

Requests go to local /api/forecast. From the repo root, run python examples/web_demo/server.py, then open this page. For local debugging only; do not expose to the public internet.

Autopilot (unattended)

This page only runs one-off run_forecast over HTTP. The local Autopilot CLI scans candidates (OpenClaw API or a JSON file), scores with the same engine, applies policy, and writes an audit log. It is not started from the browser.

VariableRole
AUTOPILOT_DATA_DIRData directory (policy, audit, state)
AUTOPILOT_DRY_RUNtrue / false (default true)
AUTOPILOT_CANDIDATES_FILEOptional path to candidate JSON (skips API)
LIFEFUN_API_BASE_URLLifeFun-compatible API base URL
AUTOPILOT_RPC_URLEVM JSON-RPC for non-dry-run
AUTOPILOT_CHAIN_IDChain id
AUTOPILOT_KEYSTORE_PASSWORDUnlock keystore (non-dry-run)

See examples/web_demo/README.md and AUTOPILOT.md in the repository.
